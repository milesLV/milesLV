I'm currently working on a few projects across a couple of different areas:

   An expansion of my previous project that uses **R** and **GraphQL** to map the reach of U.S. nonprofit organizations in rural areas.  
   It visualizes which causes are available where, how well-funded they are, and if they are adopting good governance practices with data from [CharityNavigator](https://www.charitynavigator.org/) and the [IRS](https://www.irs.gov/charities-non-profits/form-990-series-downloads).

   A Godot naval simulation project that I’m using to learn:
   - How to leverage AI tools like Claude Code and make (or find) skills complimentary to the project
   - OOP essentials and organization
   - More about Godot and developing something with the intent of potentially releasing it for people to enjoy and give feedback on

3. **Kaggle Competition Analysis** (Not Started, Concept)

   Kaggle provides an API for accessing competition data, and I want to explore public notebooks to understand how people approach the same problems. This would most likely use AI to standardize / summarize the data coming from it.

   Key questions:
   - How do people explore and analyze the data? What language and packages do they use?
   - Which features do they focus on?
   - _(If applicable)_ What models and tuning strategies do they use?
   - How do they evaluate and visualize results?
   - What reasoning and trade-offs shape their workflow?
   
   By comparing different solutions, I hope to identify common patterns, discover new techniques, and expand my own problem-solving toolkit.
